# on import). Pinned here to versions that both work with jax 0.4.29 and
# resolve cleanly in one `pip install -r requirements.txt` pass.
#

# 0.2.5 are the newest that resolve against jax 0.4.29, and the release
# notebooks were re-validated end-to-end on them (2026-07-29). dm-haiku is
